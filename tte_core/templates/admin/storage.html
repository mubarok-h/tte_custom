Cara menyiapkan
  1. Buka console.cloud.google.com, buat project, lalu aktifkan Google Drive API.
  2. Buat Service Account di menu IAM & Admin, lalu buat kunci dalam format JSON dan unduh.
  3. Buat folder di Google Drive, klik Share, dan tambahkan email service account (...iam.gserviceaccount.com) sebagai Editor.
  4. Salin Folder ID dari URL folder, unggah JSON di atas, lalu simpan.
  5. Tekan Uji koneksi Drive untuk memastikan konfigurasi benar.
